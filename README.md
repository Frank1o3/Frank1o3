## Packsmith

A command-line tool for creating Minecraft modpacks using the Modrinth API.

Features include:

* Initialize new modpacks
* Search and add mods, resource packs, and shader packs
* Automatic dependency resolution
* Optional dependency support
* Download all required files
* Export client or server modpacks

Packsmith is the successor to one of my earlier projects and focuses on making modpack creation reproducible and straightforward.

## GroqWave

A Visual Studio Code extension that integrates Groq-powered AI directly into the editor.

Some of its features include:

* Persistent `system.md` prompts
* Automatically generated `context.md` project summaries
* Code-aware context retrieval
* Planned conversational project memory
* AI-assisted development workflows

The project aims to reduce token usage while giving AI models a much better understanding of large codebases.
